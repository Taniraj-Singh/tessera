# Fuzzing

Tessera ships seven libFuzzer harnesses, each targeting a distinct entry point.

| Harness | Entry point | Reaches |
|---------|-------------|---------|
| `parser_fuzzer` | `header::parse` / `catalog::parse` | header + catalog decode |
| `decoder_fuzzer` | `schema::parse` + `records::decode` | schema + record batch decode |
| `serializer_fuzzer` | serialize path | round-trip serialization |
| `validator_fuzzer` | `validate::validate_bytes` | full parse + validation |
| `compress_fuzzer` | codec decompress + `decompress_frame` | RLE/LZ77 back-reference logic |
| `archive_fuzzer` | `ArchiveReader::open` + `parse_entry` | archive → frame → container |
| `pipeline_fuzzer` | `IncrementalDecoder` + `run_archive_pipeline` | chunked decode + full pipeline |

`archive_fuzzer` and `pipeline_fuzzer` cover the layered path from a single
buffer: archive directory → compression frame → codec → container header →
catalog → schema → record batch.

## Building and running (Clang + libFuzzer)

```bash
cmake -S . -B build-fuzz -DTESSERA_BUILD_FUZZ=ON -DCMAKE_CXX_COMPILER=clang++
cmake --build build-fuzz
./build-fuzz/fuzz/archive_fuzzer corpus/
```

## Seed corpus

`corpus/` holds shared seeds; ClusterFuzzLite auto-packages it. Richer,
per-harness seeds are generated by the `corpus_gen` tool:

```bash
cmake -S . -B build -DTESSERA_BUILD_TOOLS=ON
cmake --build build --target corpus_gen
mkdir -p /tmp/seeds && ./build/tools/corpus_gen/corpus_gen /tmp/seeds
```

`corpus_gen` emits a container (`container.tbc`), a schema block (`schema.bin`),
a compression frame (`frame.tfz`), and a two-entry archive (`archive.tba`). Copy
whichever inputs are relevant into `corpus/` before fuzzing.
